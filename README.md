# CSCapstone
CS Capstone: AI Escape Room - Wander, Erik, Todd

Open `Index.html` in a browser and select **Start** to open player setup.
Enter a user ID and a positive whole-number age for each of the two players,
then choose Full AI implementation, Collaborative A.I., or No A.I. implementation.
**Confirm setup** validates the fields and displays the chosen mode on the main
page. **Cancel** or Escape closes the menu without confirming.

This is a setup interface, not account authentication or a game launcher.
Player details remain in the form only while the page is open; they are not
saved to browser storage or sent to a server. The existing click logger is
unchanged.
